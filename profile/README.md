# Welcome to Himalayan Hack Club 👋

We are a student-led coding and maker community based at **Himalaya Public School** in **Rohini, New Delhi**. As a local chapter of the global [Hack Club](https://hackclub.com) network, we help students go from zero coding experience to building and shipping real-world tech projects.

### 🚀 What You'll Find Here
* **Member Projects:** Web apps, games, hardware hacks, and open-source tools built by our club members.
* **Workshop Templates:** Starter code, guides, and resources from our weekly sessions and Saturday meetups.
* **Community Collaborations:** Group builds and hackathon submissions created by students in Rohini.
